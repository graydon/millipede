# Deviations: where the code differs from the signed-off design

For the owner to review. Each entry: what the signed-off design (the old plan at `957480c`) says,
what is built, where the two texts now sit, and a proposed resolution. Differences in wording or
plain staleness were fixed in place and are not listed; this list is the differences in
substance. Nothing here is decided: the owner either accepts the code (the design text is then
rewritten and the entry moves to [decisions.md](decisions.md)) or asks for the code to change.
